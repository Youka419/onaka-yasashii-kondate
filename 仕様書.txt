# アプリ仕様書：おなかにやさしい献立ノート

この文書は「仕様書_たたき台.txt」を、実装方針の修正を入れて書き直したものです。
食材の中身は、別途いただいた一覧を1品ずつに分けて載せています。


## 1. アプリ概要

* アプリ名（仮）: おなかにやさしい献立ノート
* 使う人: 家族（ピロリ菌の除菌治療中など、胃に負担の少ない食事を一緒に作る人）
* やること:
  * その日の朝食・お弁当・夕食を見る
  * 「使っていいか」を食材名ですぐ調べる
  * 買うものを家族で共有し、買ったものが二重にならないようにする

* 位置づけ:
  * これは家族の料理メモです。治療中の食事は、医師・薬剤師の指示が優先です。
  * 画面のフッター（食材ガイドでは上部）に、次の一文を常に出します。
    「料理のメモです。食事の制限は医師・薬剤師の指示が優先です。」

* プラットフォーム（たたき台からの変更）:
  * Glideは使いません。
  * 画面は GitHub 上の Web アプリとし、GitHub Pages で公開します。
  * PCのブラウザと、スマホのブラウザの両方で使えます。
  * スマホでは「ホーム画面に追加」すると、アイコンから開けます。
  * 文字とボタンは、スーパーで片手でも押せる大きさにします。
  * 狭い画面（スマホ）を基準に作り、広い画面（PC）では横に広げます。


## 2. 画面構成

| タブ | 役割 |
| --- | --- |
| 今日の献立 | 日付ごとの朝食・お弁当・夕食。材料をお買い物リストへ送れる |
| 食材ガイド | 使っていい食材と、控えたい食材。検索とカテゴリ絞り込み |
| お買い物 | 買うもの、担当メモ、購入済み。家族で共有 |


## 3. 今日の献立

### 開き方

* 開いたときは、今日の朝食・お弁当・夕食を最初に出します。日付の一覧から探させません。
* 昨日・明日へは、左右のボタン（スマホではスワイプも可）で移動します。
* スマホ: 1日分だけ表示します。
* PC: 今日を真ん中に、前日・今日・翌日の3日を横並びで表示します。

### 1食の表示項目

* 日付
* 食事区分（朝食 / お弁当 / 夕食）
* メニュー名
* 主な食材（食材ガイドと同じ名前で書く）
* 胃への配慮・調理のコツ（例: 油を使わず蒸す、大根をおろして添える）

### お買い物への連携（たたき台からの追加）

* 各食事に「材料を買い物リストへ」ボタンを付けます。
* 押すと、その食事の「主な食材」がお買い物リストに足されます。
* すでに同じ品名があるときは、二重には足しません。

### 献立データの持ち方

献立の文面は、リポジトリ内のファイルで管理します。1食につき1行です。

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-09-27 の形式 |
| 食事区分 | 朝食 / お弁当 / 夕食 |
| メニュー名 | 料理名 |
| 主な食材 | 食材名を「、」で区切る。ガイドにある名前に揃える |
| 調理のコツ | 短文 |

献立の中身（何を作るか）は、この仕様書にはまだ入れません。画面と項目だけ先に決め、メニューは後から足します。
登録が無い日は「この日の献立はまだありません」と出します。


## 4. 食材ガイド

### 表示

* 上に検索窓を置きます。食材名の一部（「大根」「から揚げ」など）で絞れます。
* カテゴリで絞れます。区分（使っていい / 控えたい / 治療中は避ける）でも絞れます。
* カテゴリは折りたたみのカードにします。開くと、その中の食材が1品ずつ並びます。
* 検索したときは、閉じたカードの中も探して、当たった品だけ開いて出します。

### 1品の持ち方（たたき台からの変更）

たたき台では、1行に「キャベツ、白菜、大根…」と複数品が並んでいました。
検索で「大根」が拾いやすいよう、1食材につき1行にします。

| 項目 | 内容 |
| --- | --- |
| カテゴリ | 下の5分類 |
| 区分 | ◎ 使っていい / △ 控えたい / × 治療中は避ける |
| 食材名 | 検索に使う名前 |
| ポイント | なぜ使ってよいか、なぜ控えるか。記載があるものだけ |
| 工夫 | どう調理すると負担が少ないか。△でも禁止とは書かない |
| 代わりの目安 | △のとき、同じカテゴリの◎へ置き換える例。無い場合は空欄 |

### 区分の意味

* ◎ 使っていい: そのまま献立に使ってよい。工夫欄の調理を守る。
* △ 控えたい: 禁止ではありません。ポイントと一緒に、量を減らす・加熱する・皮や脂を除く、などの工夫を出します。可能なら「代わりの目安」も出します。
* × 治療中は避ける: 工夫で緩和しません。今回の一覧では、アルコール類だけがこれです（除菌治療中は厳禁、という記載どおり）。

### カテゴリ

1. 野菜・きのこ類
2. 肉・魚・大豆・卵
3. 主食
4. 調味料・だし・飲み物
5. 乳製品・おやつ

カテゴリ名「野菜・きのこ類」に、個別のきのこはまだありません。足すときは1品1行で追加します。

### カテゴリ共通の調理のコツ

食材ごとの工夫と別に、カテゴリを開いた先頭に次を出します。

1. 野菜・きのこ類
   * 生食は避け、やわらかく煮る・蒸す・レンジ加熱にする。
   * 硬い芯、皮、スジは取り除く。
2. 肉・魚・大豆・卵
   * 油を引かず、ホイル焼き、レンジ蒸し、煮浸しにする。
   * 卵は固ゆでや炒り卵より、半熟・温泉卵・茶碗蒸し・かきたま汁のように、半熟かスープ仕立てにする。
3. 主食
   * 水分を多めにして、やわらかく仕上げる。
   * 熱いまま食べず、少し冷ましてからよく噛む。
4. 調味料・だし・飲み物
   * 薄味にして、だしの風味を効かせる。
   * 酸味や辛味で味をつけず、だしと少量の味噌・しょうゆでまとめる。
5. 乳製品・おやつ
   * 冷蔵庫から出したてをすぐ食べない。常温に戻すか、少し温める。


## 5. お買い物リスト

### 表示

* チェック、品名、担当・メモ（「パパが買う」「2個」など）。
* チェックの押せる範囲は、行の高さごと広くとります。
* 未購入が上、購入済みは下にまとめ、普段は畳んでおきます。見出しに件数だけ出します。
* 担当の文字で絞れます（例: 「パパ」を含む行だけ）。
* 品名は手入力で追加できます。

### 共有と、電波が弱いとき

* 家族で同じリストを見るため、買いものの正本は Google スプレッドシートに置きます。
* 読み書きは、そのスプレッドシートに付けた Apps Script 経由にします。Glide は使いません。
* スーパーなど電波が弱い場所でも見えるよう、最後に読み込んだリストを端末に残します。
* 通信できたときに、チェックの結果をスプレッドシートへ反映します。
* スプレッドシートをまだ接続していない間は、その端末の中だけに保存して動きます。接続後に共有へ切り替えます。

### スプレッドシートの列

シート名: お買い物

| 列 | 内容 |
| --- | --- |
| 品名 | 買うもの |
| 担当メモ | 誰が買うか、個数など |
| 購入済み | はい / いいえ |
| 追加元 | 手入力 / 献立（どの食事から足したか。空欄可） |


## 6. 食材データ

区分、食材名、ポイント、工夫、代わりの目安、の順です。
ポイントが無い品は「—」にしています。工夫は、各カテゴリの調理のコツをその品に当てたものです。

* アルコール類 / 除菌治療中は厳禁 / 表示は「治療中は避ける」。代替の飲み方は出さない / —


### 6.5 乳製品・おやつ

◎ 使っていい

* プレーンヨーグルト / LG21など、胃の中の環境を整える乳酸菌入りを選ぶ / 冷やしたまま食べず、常温に戻してから食べる / —
* 牛乳 / 少量を、人肌程度のホットミルクにする / 冷たいまま飲まない。量は少なく、温める / —
* プリン / 卵と牛乳がベースで、消化の負担が少ない / 冷やしすぎない。常温に近づける / —
* すりおろしりんご / — / 酸味の強いりんごは避け、すりおろして使う / —
* 熟したバナナ / — / 熟したものを選ぶ。冷たいまま食べない / —

△ 控えたい（禁止ではない）

* チョコレート / 糖質と脂質が高い / 高脂質の菓子は量を控える / プリン、プレーンヨーグルト、熟したバナナ
* ケーキ / 糖質と脂質が高い / 生クリームやバターの多い菓子は控える / プリン、プレーンヨーグルト
* 生クリーム / 糖質と脂質が高い / かける・挟む用途では使わない / プリン、プレーンヨーグルト
* アイスクリーム / 胃を急に冷やす / 冷たい菓子は避ける。食べるなら常温に近いものにする / 人肌程度のホットミルク、常温に戻したプリン
* パイ / バターやショートニングが多い / 油脂の多い生地は避ける / 食パン（耳を落とす）、プリン
* クッキー / バターやショートニングが多い / 油脂の多い焼き菓子は避ける / 熟したバナナ、すりおろしりんご
* ドーナツ / バターやショートニングが多い。揚げてある / 揚げ菓子は避ける / プリン、パン粥
* みかん / 柑橘系の果物 / 酸味の強い柑橘は控える / すりおろしりんご、熟したバナナ
* グレープフルーツ / 柑橘系の果物 / 酸味の強い柑橘は控える / すりおろしりんご、熟したバナナ
